# Architecture

Phase 06 adds a Node TypeScript proxy bound to `127.0.0.1` that owns cloud provider credentials and exposes authenticated, origin-restricted, rate-limited structured analysis. The extension's `ProviderRouter` is the single cloud-routing choke point: it enforces local-only operation, hybrid fallback, and per-site consent.

Phase 06R (AI rescue) makes the AI path reliable end to end. A model returns a bounded **settings patch** (`shared/aiFields.ts`, schema generated from the Zod settings schemas by `shared/jsonSchema.ts`), validated by `parsePlan` with one corrective retry in `background/planner.ts`. Each request is a **job** (`background/aiJobs.ts`, persisted in `chrome.storage.session`, keepalive while running) that moves through run → preview → apply → undo. Preview is an overlay inside the content script's normal settings resolution (`shared/sitePatch.ts`), so there is a single apply path for saved settings and AI plans. Providers stream (SSE from llama-server, NDJSON with pings from the proxy) to stay inside MV3's fetch limits. The AI UI lives in the **side panel** (`src/sidepanel/`), which renders the stored job. The proxy (`server/src`) has pluggable Gemini and Claude backends, a live `smoke` check, and `extension/scripts/evalPlanner.ts` scores any model against `extension/eval/cases.json`.
