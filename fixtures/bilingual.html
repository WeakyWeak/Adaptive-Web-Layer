Setting up the Monsoon weather widget

The Monsoon widget shows a seven-day forecast for your town on any website. This guide explains how to install it, connect it to the forecast service and choose which details appear. It takes about ten minutes, and you do not need to be a programmer to follow it.

1. Install the package

Open a terminal in your project folder and run the install command below. If the command fails, check that Node.js is installed by running node --version.

npm install monsoon-widget --save
npx monsoon-widget init

2. Connect to the forecast service

The widget reads forecasts from https://api.monsoon.example.org/v2/forecast. Create a free account on the website, copy your key, and save it in a file called user_settings.json under the name API_KEY. Never share this key with anyone: it works like a password for your account.

Then call loadForecast() once when your page starts. The function waits for the forecast to arrive and draws the widget inside the element whose id you pass to it, for example weatherPanel.

3. Choose what to show

By default the widget shows temperature and the chance of rain. To add humidity and wind, set showHumidity and show_wind to true in the same settings file. Larger widgets look best in a sidebar that is at least 300 pixels wide.

If the forecast does not update, wait an hour: the service refreshes its data every sixty minutes to keep it free for everyone. For help, write to support@monsoon.example.org or read the answers to common questions at www.monsoon.example.org/help.
