Technical Documentation

Installation

Install the package using your preferred package manager:

npm install adaptive-web-layer
# or
yarn add adaptive-web-layer
# or
pnpm add adaptive-web-layer

Configuration

Create a configuration file at the root of your project. The extension reads this file on startup and applies the specified preferences immediately:

{
  "profile": "study",
  "fontSize": 17,
  "lineHeight": 1.8,
  "theme": "light",
  "siteOverrides": {
    "news.ycombinator.com": { "fontSize": 14 }
  }
}
⚠ Note: Site overrides take precedence over the global profile. The resolution order is: defaults → global → named profile → site override.

API Reference

applyConfig(config)

Applies the given configuration object to the current page. This function is idempotent; calling it multiple times with the same config is safe.

import { applyConfig } from 'adaptive-web-layer';

applyConfig({
  fontSize: 18,
  lineHeight: 1.9,
  theme: 'dark'
});

revertAll()

Reverts all applied changes and restores the original page styles. This is equivalent to calling revert() on every active operation.

Examples

The following example shows how to set up a "Study" profile with large text, generous spacing, and sepia toning for comfortable long-form reading:

const studyProfile = {
  profile: "study",
  fontSize: 19,
  lineHeight: 2.0,
  letterSpacing: 0.02,
  theme: "sepia",
  maxWidth: 680,
  fontFamily: "'Georgia', serif"
};

Troubleshooting

Extension not applying styles

Check that the extension is enabled for the current site. Open the popup and verify the status badge shows Extension active. If the page is listed under a site override with enabled: false, the extension will not apply any changes.
